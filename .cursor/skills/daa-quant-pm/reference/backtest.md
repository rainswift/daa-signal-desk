# Backtest — 回测 / 模拟验收

把「看起来很猛的曲线」变成可拒绝的验收门槛。读 [a-share-rules.md](a-share-rules.md)。

## 验收规格必含

1. **区间：** 样本内 / 样本外 / 滚动；明确禁止用样本外调参后假装样本外
2. **基准：** 指数或组合；调样规则
3. **成交模型：** 价格（开/收/VWAP 等）、涨跌停、停牌、数量约束、T+1
4. **成本：** 佣金、印花税、滑点；默认参数表
5. **容量假设：** 是否考虑参与率 / 冲击；不考虑则标明「研究用、不可直接扩规模」
6. **通过线：** 主指标阈值 + 护栏（回撤、换手、集中度、违规次数）
7. **失败即停条件：** 哪些结果直接否决上线

## 反偏差清单（逐项勾）

- [ ] 无未来函数（含成分、财务、涨停状态）
- [ ] 无幸存者偏差静默
- [ ] 复权口径与实盘一致或差异已知
- [ ] 过拟合防控：参数个数、试错次数披露或限制
- [ ] 成本敏感性：至少 ±一档成本压力测试
- [ ] 分阶段：牛/熊/震荡或按年份稳定性

## 输出模板

```markdown
# Backtest Acceptance: <策略/功能>

## Setup
## Pass / Fail Gates
## Bias Checklist
## Sensitivity
## Decision
- [ ] 通过研究阶段
- [ ] 可进仿真
- [ ] 可进小规模实盘
- [ ] 否决（原因）
```

禁止把回测通过写成对客收益承诺。
