# Clarify — 术语与表述

统一对内语言，卡住对外越权表述。

## 术语表规则

- 一词一义；弃用别名列入「禁止再用」
- 信号 / 因子 / 特征 / 预测值：若混用，强制拆定义
- 收益类词汇标注：毛/净、是否含成本、是否相对基准

## 对内 vs 对外

| 对内可用 | 对外需谨慎 |
|---|---|
| 目标权重、研究信号 | 「建议立即买入」类指令 |
| 回测超额 | 未附区间/费用/风险的收益承诺 |
| 实验组 | 暗示保本或稳赚 |

发现越权句式：改写为中性描述或加「待合规审定」占位，不要装作已审过。

- 更新后的术语表 diff
- 改写前后对照（仅关键句）
- 仍存歧义的开放问题
