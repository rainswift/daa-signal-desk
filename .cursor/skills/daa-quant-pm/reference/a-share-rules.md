# 大 A 规则速查（产品规格用）

只记写规格时常踩的点；细则以交易所/法规原文为准，此处用于提醒而非法律意见。

## 交易机制

| 主题 | 产品含义 |
|---|---|
| T+1 | 当日买入普通股一般次日才可卖；当日可用资金/仓位状态机必须区分「可卖持仓」 |
| 涨跌停 | 触及涨跌停可能无法成交；回测成交模型不得假设限价必成 |
| 竞价 | 开盘集合竞价与连续竞价时段不同；信号时点要落到具体时段 |
| 最小变动价位 / 整手 | 下单数量与价格取整规则影响仿真与实盘偏差 |
| 停牌 | 不可交易；因子与持仓处理需定义（冻结 / 剔除 / 按可交易子集） |

## 板块与品种差异（务必点名适用池）

- 主板 / 创业板 / 科创板：涨跌幅、上市初期机制、投资者适当性可能不同
- ST / \*ST：风控与池子规则常单独处理
- 指数成分：用哪条指数、何时调样、是否点位时间对齐（point-in-time）
- 可转债、ETF、融资融券：机制与股票不同，禁止混用同一成交假设

## 价格与收益

- **不复权：** 展示真实历史成交价时常用
- **前复权：** 研究收益/因子常用；注意权息日跳变处理
- **后复权：** 长期净值类展示有时使用
- 写清：分红、配股、送转在因子与回测中的处理

## 常见产品陷阱对照

| 陷阱 | 规格应写什么 |
|---|---|
| 用当日收盘因子做「开盘买入」 | 信号可用时点 = T 日收盘后；最早下单 = T+1 开盘（或显式隔夜单规则） |
| 成分股用最新成分回测历史 | 成分调整表 + 生效日；禁止 look-ahead membership |
| 忽略一字板买不到 | 涨停无法买入 / 跌停无法卖出 的成交规则 |
| 费率写「忽略」 | 至少给默认成本假设，并允许参数化 |

## 表述边界

- 对内：可用「信号、目标权重、建议仓位」等研究语言
- 对外：避免未授权的投资建议口吻；收益展示需样本区间、费用、风险提示占位
