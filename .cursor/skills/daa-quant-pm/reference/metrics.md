# Metrics — 指标口径

消灭「同一个词、三套数」。每个指标一张卡，可对账。

## 指标卡模板

```markdown
## <指标名>（英文名 / 缩写）

- **业务含义：** 一句话
- **公式：** 
- **窗口 / 频率：** 
- **Universe：** 
- **复权 / 成本：** 
- **缺失 / 停牌处理：** 
- **point-in-time：** 是 / 否；生效规则
- **权威计算方：** 研究 / 工程 / 风控
- **对账键：** 日期 + 标的 + …
- **用途：** 研究 / 监控 / 对客（不可混用未声明）
- **非目标：** 本指标不用于…
```

## 大 A 量化常用族（按需选用，必须定义）

| 族 | 示例 | 注意 |
|---|---|---|
| 预测力 | IC、RankIC、ICIR | 标明滞后期与行业/市值中性化是否做 |
| 组合 | 超额、跟踪误差、换手、集中度 | 基准指数与调样规则 |
| 交易 | 成交率、滑点、拒单、涨停买不到比率 | 与仿真模型对齐 |
| 风险 | 最大回撤、波动、杠杠、违规触线次数 | 计算频率与估值时点 |
| 产品 | 激活、留存、任务完成率 | 与投研指标分开命名 |

## 规则

- 主成功指标只能有一个；其余标为护栏或诊断。
- 对客展示指标必须另附风险提示占位与样本说明。
- 变更口径 = 版本号 + 生效日 + 回填策略（是否重算历史）。
