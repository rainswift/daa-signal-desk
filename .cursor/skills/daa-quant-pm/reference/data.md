# Data — 数据与因子契约

把字段、时点、依赖画清楚，避免工程与研究各算各的。

## 交付物

1. **数据字典表**（实体级）
2. **因子/信号说明书**（若有）
3. **依赖图**（上游 → 本产品 → 下游消费者）

## 数据字典列

| 字段 | 类型 | 语义 | 权威源 | 更新频率 | 延迟 | 时区/交易日 | 缺失策略 | 消费者 |
|---|---|---|---|---|---|---|---|---|

主键、自然键、是否允许修订（restatement）必须写明。

## 因子 / 信号说明书

```markdown
## <因子名>

- 定义与经济解释（禁止只有公式无解释）
- 输入字段与预处理（去极值、标准化、中性化）
- 计算时点与**最早可用时点**
- Universe 与剔除（ST、停牌、上市不满 N 日…）
- 预期方向与失效条件
- 已知偏差与缓解
- 负责人 / 版本
```

## Point-in-time 检查清单

- [ ] 财务字段用公告日/入库日，而非报告期偷懒对齐
- [ ] 指数成分用历史生效成分
- [ ] 行业分类版本与切换日
- [ ] 复权因子版本与切换

## Stop

只定义契约，不在此实现管道。口径争议转 `metrics`；回测能否用这套数据转 `backtest`。
