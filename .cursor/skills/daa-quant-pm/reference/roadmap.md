# Roadmap — 优先级与切片

把愿望列表收成可发布序列，暴露依赖与风险。

## 方法

1. 列出候选能力（来自 PRD / 访谈 / 技术债）
2. 每项估：**用户价值、风控必要性、依赖成本、不确定性**
3. 强制找出 **下一个可发布切片（MVP）**：能闭合一条主用户路径 + 可观测主指标
4. 标出硬依赖：数据开通、合规评审、柜台/行情、研究签字

## 输出模板

```markdown
# Roadmap

## Now (当前切片)
- 目标：
- 包含：
- 不包含：
- 退出标准：

## Next
- ...

## Later
- ...

## Parking lot
- 想法但无证据/无业主：...

## Risks & dependencies
- ...
```

## 规则

- Now 切片必须能 `backtest` 或产品任务验收，二者至少其一。
- 禁止把「平台化重构」单独作为 Now，除非当前主路径被其阻塞。
- 每个阶段一个主成功指标，避免平行三件套都叫 P0。
