# Polish — 交付前收口

在手写规格「基本完成」后做最后一遍，目标是别人能无口头补充地执行。

## 清单

- [ ] 术语表完整；全文同一概念同一词
- [ ] In/Out 边界锋利；没有「等」悬浮需求
- [ ] 每个 P0 有验收用例
- [ ] 指标卡可对账（公式 + 频率 + 权威方）
- [ ] 信号时点与大 A 约束交叉检查通过
- [ ] 开放问题集中在一节，且每条有业主
- [ ] 对客/对内表述已分离
- [ ] 版本号、作者、日期、变更摘要

## 做法

1. 通读目标文档，只修会阻碍执行的问题
2. 小矛盾直接改；大范围重写先征得同意
3. 收尾给「可以进入开发 / 仿真 / 评审」的明确声明与残留风险
