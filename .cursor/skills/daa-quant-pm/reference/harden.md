# Harden — 异常与失败模式

把「天气好」的规格补成可上线规格。

## 必补状态

| 状态 | 要定义的行为 |
|---|---|
| 行情延迟 / 中断 | 降级、告警、是否禁止新开仓 |
| 涨跌停 / 停牌 | 委托、撤单、调仓顺延 |
| 数据修订 | 是否重算、影响区间 |
| 参数误改 | 权限、审批、审计、回滚 |
| 回测与实盘偏离超阈 | 熔断阈值与责任人 |
| 权限不足 | 可见不可用 vs 隐藏 |
| 供应商切换 | 双源对账失败时的策略 |

## 输出

- 状态机图（可用 mermaid 或表格）
- 告警矩阵：条件 → 级别 → 通知人 → 自动动作
- 新增验收用例（每个 P0 异常至少一条）

与 `audit` 的 Fail 项对齐逐条关闭。
