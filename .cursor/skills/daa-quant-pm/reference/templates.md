# Templates — 快启骨架

按需复制；细节以各命令 reference 为准。

## 一页问题陈述

```markdown
# Problem Brief
- 用户与场景：
- 当前痛点：
- 成功时可见变化：
- 非目标：
- 硬约束（大 A / 合规 / 数据）：
```

## 用户故事

```markdown
作为 <角色>，我希望 <能力>，以便 <业务结果>。
验收：<可观测条件>
```

## 决策记录（ADR 轻量）

```markdown
# ADR: <标题>
- 状态：提议 / 已定 / 废弃
- 上下文：
- 决策：
- 后果：
- 替代方案：
```

## 发布说明

```markdown
# Release Notes
- 版本：
- 用户可见变化：
- 指标口径变更：
- 风险与回滚：
```
