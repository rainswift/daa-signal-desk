# Distill — 砍到最小可发布

范围膨胀时用。保留一条主路径，其余降级或删除。

## 步骤

1. 写出当前宣称的全部能力
2. 标出**唯一**主用户任务
3. 只保留完成该任务的最少功能、最少指标、最少数据
4. 其余进 Next / Later，并写「为何此刻不做」
5. 更新成功指标：只留一个主指标 + 必要护栏

## 切割启发式

- 能用手填/半自动顶住一周的，不当作 P0 自动化
- 没有验收的「平台能力」先删
- 多个 Universe / 多策略并行 → 先锁一个池、一个信号族
- 对客精美展示 < 对内可对账；内部工具优先真相

输出：一页 MVP 说明 + 砍掉清单。可接着 `prd` 重写瘦身版或 `roadmap` 重排。
