# Craft floor — 大 A 量化产品不可妥协底线

在写/改任何规格前读完。这些不是风格偏好，是质量地板。

## Absolute bans

1. **未来函数入产品。** 不得把仅当日收盘后可知的信息当作盘中可用信号，除非明确标注「收盘后批处理」并定义可用时点。
2. **用回测收益承诺实盘。** 规格可引用回测作证据，但验收与对客表述必须拆开「研究指标」与「产品承诺」。
3. **忽略交易成本与约束。** 至少声明：佣金/印花税/滑点、涨跌停不可成交、停牌、最小交易单位、T+1 可卖约束。
4. **幸存者偏差静默。** 指数成分、退市、ST 处理必须写明纳入/剔除规则与时点（point-in-time）。
5. **复权口径含糊。** 价格/收益计算必须标明前复权/后复权/不复权及用途（展示 vs 回测）。
6. **把海外市场机制直接套大 A。** 禁止默认 T+0、做空自由、盘后可知即可盘中用。
7. **对客输出越权。** 未声明牌照/适当性流程时，不写具体买卖指令式文案；对内投研与对客话术分离。

## Required reflexes

- 每个指标：定义、公式、窗口、更新频率、缺失值处理、责任人。
- 每个信号：触发条件、生效时点、失效条件、与订单的映射。
- 每个状态：正常 / 降级 / 熔断 / 人工介入的进入与退出。
- 每个数据源：供应商、延迟、字段权威源、对账键。
- 每个发布：回滚条件、灰度范围、监控告警。

## Definition of done (规格)

- [ ] 主用户与主成功指标唯一且可测
- [ ] 范围外清单明确（Out of scope）
- [ ] 数据依赖与 point-in-time 规则写清
- [ ] 回测/模拟验收用例 ≥ 3 条（含 1 条失败/边界）
- [ ] 合规与风控红线已点名或标注 N/A 及理由
