# Command guidance

## Workflow questions

只给建议，不自动执行命令。需要时查阅各命令 reference 的前置与范围。若用户同时要求执行，再执行。

## 无参数路由：情境化菜单

用户只调用 `/daa-quant-pm`（或同义「大A量化产品经理」）且无子命令时：

1. 检查是否存在 `PRODUCT.md` / `QUANT.md`。都没有 → 菜单首推 `/daa-quant-pm init`，并说明原因；仍展示完整命令表，**不要静默进入 init**。
2. 否则根据仓库线索给出 **2–3 个最高价值下一步**（每条一行理由），再附完整命令菜单。
3. **永不自动执行命令**；推荐需用户确认。

推荐启发式：

| 信号 | 倾向命令 |
|---|---|
| 无产品真相文件 | `init` |
| 新功能描述模糊 | `shape` |
| 要写需求/故事 | `prd` |
| 指标口径扯皮 | `metrics` |
| 字段/因子定义不清 | `data` |
| 回测能否上线有争议 | `backtest` |
| 文档已有但怕漏 | `critique` → `audit` |
| 排期/取舍 | `roadmap` |
| 临近交付 | `polish` / `harden` |
| 文案或术语混乱 | `clarify` |
| 范围膨胀 | `distill` |

按意图分组展示：新建 / 规格化 / 验收与风控 / 对齐与发布。
